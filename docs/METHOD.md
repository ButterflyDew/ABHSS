# ABHSS 方法说明

ABHSS 的主线是：把精确 GST 的子集搜索组织为普通子树 D 与锚定子树 A，只物化平衡完成需要的层；让已生成的 A1 和 D 同时服务下界与真实上界；在 Enhanced 中以补集反向 H 替换高层前向展开。Base 与 Enhanced 共享同一个求解器，差异是证书的安全增加或同一数学职责的替换。

本文对应当前源码。实现入口及函数定位见[代码导读](CODE_GUIDE.md)。

## 1. 问题与记号

给定无向图 $G=(V,E,w)$，边权非负，查询包含 $g$ 个非空顶点组 $K_0,\ldots,K_{g-1}$。组可以重叠。目标是找到触及每个组的连通子图；去掉环不会增加费用，因此最优解可取为树：

```math
\mathrm{OPT}(G,\mathcal K)=\min\left\{\sum_{e\in E(T)}w(e):T\text{ 连通},\ V(T)\cap K_i\ne\varnothing\ \text{ 对所有 }i\right\}.
```

记 $n=|V|$、$m=|E|$。选一个永久锚组 $K_a$，其余组集合记作 $N$，大小 $k=g-1$。状态 mask 只编码 $N$；查询距离和证书仍按原始组编号读取。

| 记号 | 含义 |
|---|---|
| $d_i(v)$ | 顶点 $v$ 到组 $K_i$ 的最短距离 |
| $D(S,v)$ | 包含根 $v$、覆盖非锚组子集 $S$ 的最优 rooted 子树值 |
| $A(S,v)$ | 包含根 $v$、覆盖锚组及 $S$ 的最优 rooted 子树值 |
| $H(S,v)$ | 已覆盖补集 $N\setminus S$、等待锚组及 $S$ 的外侧值 |
| $U$ | 当前真实可行解的费用上界，只会下降 |
| $h,q$ | $h=\lfloor g/2\rfloor$，$q=\max(0,h-1)$ |

公式首先描述未剪枝的逻辑值。实际只保存仍可能参与严格改善 $U$ 的状态；缺失 row 值不能一概理解为全图 rooted 最优值无穷。后面的精确性论证要求保留一个改善解的完整推导，而不是要求所有 rooted 子问题都无条件完整求出。

程序求最优权值，不序列化最终最优树。空查询返回 0；不存在共同可行连通分量时返回 -1。代码支持 $g\le16$，允许零权边、重边、自环和非连通图。

## 2. 平衡分解与两种执行方式

在一棵最优树中为每组指定一个命中的代表，将组质量放在代表顶点上。取组质量的树重心，各离开重心的分支至多含 $h$ 个组。重心处的组可作为零边分支处理。总质量为 $g\le2h+1$，这些分支可分为至多三部分，每部分至多 $h$ 个组。

这里用到简单的装箱引理：将大小至多 $h$、总和至多 $2h+1$ 的正整数按递减顺序放入容量为 $h$ 的三个箱，总能放下。若第四箱首项为 $x>h/2$，前面三箱各含一项至少为 $x$，总和至少为 $2h+2$；若 $x\le h/2$，前面每箱负载至少为 $h-x+1$，连同 $x$ 的总和至少为 $2h+3$。均矛盾。

令含锚组的一部分为 A，其余两部分为 D，则存在同根完成式：

```math
U\leftarrow\min\{U,A(S,v)+D(B,v)+D(C,v)\},\qquad S\mathbin{\dot\cup}B\mathbin{\dot\cup}C=N,
```

其中 $|S|\le h-1=q$，$|B|,|C|\le h$。因此不必构造全组数深度的 A。

Base 物化 D 到 $h$、A 到 $q$。Enhanced 保留共同的最小非空锚定前缀，令 $\ell=\min(1,q)$；若 $\ell<q$，D 只物化到 $q$，高层由 $\ell<|S|\le h$ 的 H 实现，最高 H 是辅助半层。若没有非空后缀，则直接使用完整前向完成方式。这些边界由递推域推出，不是经验性的组数阈值。

| 职责 | Base | Enhanced |
|---|---|---|
| 距离与候选根 | 有界组距离初始化 | 完整组距离初始化，返回相同结构 |
| 初始见证 | 根路径树 | dual-primal 树；树 DP 不变 |
| A1 | 共同的提前构造、cone、fallback 与缓存 | 完全相同的内核，不接入 dual |
| ordinary D | 同根合并、图闭包与 branch | 相同递推，增加对偶下界 |
| 高层 | 前向 A 及 D 半层 | 反向 H，含承担 D 半层职责的辅助层 |
| 条件式证书更新 | 见证树 DP | 相同见证树 DP，另有 residual/support 更新 |

## 3. 预处理：廉价证书与真实路径

### 3.1 可行性和分量覆盖下界

加载时计算普通连通分量。若没有一个分量同时含有所有组的候选顶点，查询不可行。对于可行查询，再考虑零权边诱导的连通分量，将每个被查询触及的分量映射为它覆盖的组 mask。

用组维度 set-cover DP 求覆盖所有组至少需要多少个零权分量，记为 $c_0$。若 $c_0=1$，最优值是 0。否则任何可行树至少连接 $c_0$ 个零权分量，至少使用 $c_0-1$ 条正权边。设全图最小正边权为 $w_{\min}^{+}$，则：

```math
L_0=(c_0-1)w_{\min}^{+}\le\mathrm{OPT}.
```

纯正权图中，每个顶点本身就是零权分量；利用加载时缓存的最小边权，只排序查询触及的顶点即可，不必逐查询重扫所有边。

### 3.2 统一的距离—根初始化

`BuildDistanceRootInitialization` 返回组距离表、候选根 $r$ 和有限真实上界。Base 先以规范终端的最短路树构造可行上界，用它截断多源最短路；Enhanced 的 directed-cut 需要完整势，因此保存全图距离。两种实现随后都扫描共同根的距离和，改善候选根与上界。

有界表在 cutoff 外返回的是下界占位，不是已找到的路径。`GroupRow::operator[]` 可用于下界；`ExactValueOrInf` 只返回真实距离，供 DP 种子和路径恢复使用。稀疏表按顶点保存值，并用 membership/rank 位图定位；稠密与稀疏布局按实际所需字节数选择。

随后两边共同恢复候选根到各组的最短路径并集，按原边编号去重，得到更紧上界。锚组选择为初始化根处距离最大的组，并列按组编号固定。锚组固定后不再修改。

当 $g\le3$ 时，任意最优树可在一个点分成至多三条代表路径，故：

```math
\mathrm{OPT}=\min_{v\in V}\sum_{i=0}^{g-1}d_i(v).
```

两边都用共同的有界初始化直接求出这一精确基例，无需 witness、dual 或指数状态表。

### 3.3 真实路径生长上界

两边在各自 witness 构造后调用同一个路径生长函数。对每个有序组对恢复一次最近种子路径，枚举第三个早期目标组，然后不断连接当前树最近的未覆盖组。路径中命中的其他组同时记为已覆盖。

恢复只沿最短距离的 tight edges，访问标记阻止零权环；每条加入的原边只计费一次。候选费用非负且单调增长，达到当前上界即可停止本候选。这样得到的是原图中的连通可行子图，不是把一个下界误当答案。

## 4. 可采纳剩余下界

对尚需覆盖的原始组集合 $R$，最便宜的下界为：

```math
L_{\mathrm{far}}(v,R)=\max_{i\in R}d_i(v).
```

预处理为每个顶点缓存全体组中的最远组；它仍在 $R$ 时直接返回，否则扫描 $R$。

令组间松弛距离为 $\delta(i,j)=\min_{u\in K_i,v\in K_j}\mathrm{dist}(u,v)$。在这个组维度图上做固定端点 Hamilton 路径 DP，记覆盖 $R$、端点为 $i,j$ 的值为 $P_R(i,j)$。有界距离使两个方向不对称时，实现取两个方向路径值的较小者作为这一无序端点对的值。一般组间距离不满足三角不等式；证明只使用每条组间连接不大于相应真实树遍历段，不依赖三角不等式。

固定一个端点组，对另一端取最小，再对固定端点取最大，得到 rooted tour 下界：

```math
L_{\mathrm{tour}}(v,R)=\frac12\max_{i\in R}\min_{j\in R\setminus\{i\}}\bigl(d_i(v)+P_R(i,j)+d_j(v)\bigr).
```

空集取 0，单组取该组距离。任意覆盖 $R$ 的 rooted 树可倍增为闭合遍历；按首次命中的组抽取路径，各松弛距离不超过对应遍历段，总和至多两倍树权，因此上述值是下界。有界组距离可能使矩阵不对称，但每项仍不大于真实连接费用，下界方向保持。

记 $P(R)=\max_i\min_{j\ne i}P_R(i,j)$，则完整 tour 求值至多为 $L_{\mathrm{far}}+P(R)/2$。这只是 tour 值的上包络：已有下界达到它时，跳过端点扫描不会改变最大下界；不能直接把上包络作为剪枝下界。

普通 future 取 farthest、tour 的最大值。Enhanced 另加入 directed-cut；D 阶段还使用下一节的公共 A1。

## 5. 提前 A1：让前向状态先服务 D

对非锚组 $i$，$A(\{i\},v)$ 是连接锚组、组 $i$ 和根 $v$ 的最优值。先在同根合并两个精确组距离，再沿图闭包，即可构造这张行。只要 $q>0$，两边都在 D 之前执行它，之后直接移交前向模块。

令 $R_i$ 为锚组和 $i$ 之外的原始组集合。预处理固定选择使 $p_j(R)=\min_{t\ne j}P_R(j,t)$ 最大的组 $j^*(R)$。共同 continuation 为：

```math
C(v,R)=\max\left\{L_{\mathrm{far}}(v,R),\frac{d_{j^*(R)}(v)+p_{j^*(R)}(R)}2\right\}.
```

单组时直接取组距离，空集为 0。第二项的可采纳性可由从指定组代表出发、最终停在 $v$ 的树遍历证明：路径松弛值加 $d_j(v)$ 不超过两倍树权。固定 $R$ 后端点组是常量；距离沿边至多变化该边权，因此 $C$ 是 1-Lipschitz。

在构造开始时固定上界 $U_0$，只保留满足以下条件的精确 A1 值：

```math
A(\{i\},v)+C(v,R_i)<U_0.
```

沿最短闭包路径，已付距离增加而 $C$ 至多下降相同边权，所以到达 cone 内目标所需的前驱不会先被 cone 剪掉。缺失位置因而可以返回：

```math
\underline A_i(v)=\max\{0,U_0-C(v,R_i)\}.
```

row 内返回精确值，row 外返回上述下界。D 的补全部分必须同时连接锚组及每个未覆盖组 $i$，故可取这些 A1 下界的最大值。cone 和 fallback 必须由同一个 $C$ 定义；A1 不读取 Enhanced 的 dual，避免改变缺项的证明含义。

### 查询缓存与购买

每个顶点先按需缓存最大的两个 singleton 编号及其精确值下标。任一前两名仍在剩余 mask 中就直接返回；否则查询尾部。

缓存升级只按结构工作量决定。设第 $i$ 行长度为 $z_i$、一次二分比较估计为 $b_i=\max(1,\lfloor\log_2z_i\rfloor+1)$。全图 top-two 的工作估计为：

```math
B_{\mathrm{scan}}=\sum_{i\in N}\bigl(2n+(n-z_i)(k+2)\bigr).
```

每次首次查询顶点支付 $\sum_i(b_i+1)$，达到该成本后顺序物化前两名。尾部长度 $t=k-2$，完整排名的成本为：

```math
B_{\mathrm{rank}}=B_{\mathrm{scan}}+n\left(\frac{t(t-1)}2+t\right).
```

实际尾部二分按被查询 bit 的 $b_i+1$ 累计，达到成本后以 byte 保存完整次序。每个 mask 的精确租金和用子集递推预存，避免为计费再遍历 bit。排名和 locator 不压缩 `double`；最终仍读取原值或同一 fallback。全部查找缓存在 D 后释放，A1 行仍保留。

## 6. D：同根合并、图闭包与规范 branch

空集值为 0，单组值为组距离。对多组 $S$，先合并，再做图闭包：

```math
B(S,v)=\min_{\varnothing\ne X\subsetneq S}\bigl(D(X,v)+D(S\setminus X,v)\bigr),\qquad
D(S,v)=\min_{u\in V}\bigl(B(S,u)+\mathrm{dist}(u,v)\bigr).
```

实现固定最低 bit 消除左右对称。若 $D(S,v)<B(S,v)$，将该位置标为 branch；单组天然是 branch。等于同根拆分值的状态仍保留其数值，但作为分支再次组合前可继续展开。每次展开严格减小组 mask，最终得到由规范 branch 组成的等价推导；这减少重复组合而不丢掉必要完成。

每张行先聚合所有同根 seed，再对每个顶点求 future，以 `distance+future` 为堆序执行非负边闭包。只有候选仍满足 `distance+future < U` 才接受。这里的 future 针对一个完整树分解中尚未支付的部分；最优树的对应分解仍有不大于其真实补全部分的证书，因此严格改善解总保留必要的推进路径。

堆允许重复入堆，并按真实距离跳过过期项。源码没有永久 settled 标志来阻止更小标签再次进入；证书分阶段计算或增强后，不能未经证明声称每个顶点只弹出一次。

### 两种下界缓存

Base 先做廉价 farthest/A1 检查，存活候选缓存完整 future。Enhanced 增加 dual，并逐阶段缓存 dual、farthest、A1、tour 已完成的最大值；较大标签被中途拒绝后，更小标签仍可从未完成阶段继续。缓存阶段表示已经算了什么，不表示顶点永久关闭。

Enhanced 还在观察到重复拒绝后保存 row-local 拒绝前沿，复用后续必被拒绝候选的比较。虚拟阈值不进入堆、不发布成 D、不计状态。更小候选通过完整证书后才转成真实标签；行结束时复位未转化的位置。涉及浮点阈值时以 `nextafter` 修正到满足原始加法比较的值，保持非负标签上的单调拒绝关系。

## 7. 见证上界与条件式证书更新

### 7.1 两棵树、同一个 DP

Base 把共同根路径并集整理为根路径 witness；Enhanced 把 directed-cut 恢复的 primal 整理为 dual witness。两者都以真实锚组终端为根，父指针只接受严格距离改进，零权等距时不重挂。

`EvaluateWitnessTree` 自底向上求值。每个树顶点可以接入精确单组路径和已经发布的 rooted D；局部按组子集分拆，再对子树做子集卷积。使用某个子树时加上通往它的真实父子边费用，最后在锚根的虚拟父节点读取全非锚 mask。

这些操作组合的都是以同一顶点连接的真实可行子图。即使不同部分共享原边，相加只可能重复计费，结果仍是可行上界，不会伪造更低答案。它不是“只在 witness 边上求原问题最优”：D 种子可以包含树外的真实子树。

若 witness 有 $t$ 个顶点，树上的卷积时间为 $O(t3^k)$，按有序行二分读取 D 种子另需至多 $O(t2^k\log(n+1))$；空间为 $O(t2^k)$。两边都从 `rent=0` 开始，A1 与 D 的实际堆弹出和边扫描累计到同一个购买式后才调用它：

```math
B_{\mathrm{tree}}(t,k)=t\left(\frac{3^k-1}{2}+3^k\right).
```

购买式按局部拆分和父子卷积的结构工作量估计，并不等于逐指令成本；上面单列的 D 查找成本仍计入实际求值时间。

没有新 D 输入时不重复购买同一个结果。若 A1 构造中购买收紧了上界，丢弃当前未完成 pass，以新 $U_0$ 整轮重启；不能把新 cutoff 与旧 cone 混在一张行里。

### 7.2 Directed-cut 与真实 primal

将每条无向边看作两个有向弧。每个组的非负势 $\pi_i$ 在本组为 0，并满足弧容量约束：

```math
\sum_i[\pi_i(u)-\pi_i(v)]_+\le w(u,v).
```

对任意从根 $v$ 覆盖组集合 $R$ 的树，沿根到各组的有向路径望远镜求和，再按上式合并边费用，得到 $L_{\mathrm{cut}}(v,R)=\sum_{i\in R}\pi_i(v)$ 不超过树权。

按组在 residual 上求到组的距离、截断到候选根处的值，再扣除正势差，可以保持容量非负与上述约束。初始最短路只重松弛 residual 已改变的弧。截断势在 cone 外为常量，边两端都在 cone 外时梯度为零；更新只需枚举 cone 涉及的边，并在每条无向边上扣除唯一可能为正的方向。

在 residual 数值零弧上按原边权逐次接入未覆盖组，得到真实 primal。设施点 DP 只沿允许的真实路径组合，进一步改善上界。恢复时的容差只扩大可选的上界路径，不用来证明下界闭合。

### 7.3 一次性 residual 更新与支撑图 DP

Enhanced 另累计实际搜索工作。达到 residual 重建、势补全和 primal 恢复的静态结构成本，且已发布 D payload 至少覆盖一遍顶点域时，购买一次全势闭包：利用尚未支付的 residual 容量增加势，重新恢复 primal/facility 上界。

此次购买后，路径生长额外固定第四个早期组。若它严格改善上界，把该路径候选与 primal 的真实边取并，登记为固定支撑图。后续 witness evaluator 可改用此图的 DP；这是同一“把已发布 D 连成可行上界”的职责替换。

支撑图有 $s$ 个顶点时，Floyd 建立真实路径度量；每个 mask 先使用单组距离或 D 作为 direct seed，再同根合并、做度量闭包，最后只在真实锚组终端读取答案。一次完整求值的购买式为：

```math
B_{\mathrm{sup}}(s,k)=\frac{s(3^k-2^{k+1}+1)}2+(2^k-1)s^2+s^3+(2^k-1)s.
```

新 D(M) 只能影响包含 M 的 mask，因此再次购买时只重算这些超集；如果证书收紧导致旧 D 行被重滤，下一次重算全部 mask。固定支撑图的度量无需重建。上下界更新都是单调安全改进，不改变主搜索的精确目标。

## 8. A 与 H：两种高层完成方式

### 8.1 前向 A

以 $A(\varnothing,v)=d_a(v)$ 为基例，前向递推为：

```math
A(S,v)=\mathrm{closure}\left(\min_{\varnothing\ne B\subseteq S}\{A(S\setminus B,v)+D(B,v)\}\right).
```

ordinary 一侧用规范 branch；可继续同根拆分的值通过更小前缀展开。按 $|S|$ 递增计算，公共 A1 直接移交而不重新生成。每张 A 用第 2 节的平衡式尝试补上两块 D；无需后续读取的末层只消费，不持久保存。

### 8.2 补集转置的 H

H 表示 $S$ 外已经支付的部分。令 $Q=N\setminus S$，对全部目标 $\ell<|S|\le h$ 准备直接终端 $T(S,v)$：若 D(Q) 已物化，直接读取它；否则枚举两块互斥 ordinary 集合之和，要求两块都不超过 $q$、并为 Q。

已有完整 D(Q) 时，它及其图闭包逐值支配同目标双块和，不再枚举该 pair。D(Q) 被安全剪掉的位置也不能借较大的 pair 恢复成严格改善解。其余较大补集由 successor 递推承担：

```math
H(S,v)=\mathrm{closure}\left(\min\left\{T(S,v),\min_{\substack{\varnothing\ne B\subseteq N\setminus S\\|S\cup B|\le h,\ |B|\le q}}\{H(S\cup B,v)+D(B,v)\}\right\}\right).
```

按 $|S|$ 递减计算。successor 读取 ordinary 的全部值，而不是只读 branch：原规范 split 的 branch 可能已位于 H 代表的补集侧。额外同根候选仍是可行子图之并，安全性不受影响。

逐个普通规范 split $Q=X\mathbin{\dot\cup}Y$ 可证明覆盖完整：若 D(Q) 已物化，由单块终端覆盖；若两侧都不超过 q，由直接双块终端覆盖；否则较大一侧至少为 h，另一侧大小至多为 $h-|S|$，可加回 S，落在已经完成的 H successor 域中。归纳并执行图闭包，得到仍可能严格改善 U 的区域内 $H(S,v)=D(N\setminus S,v)$。

最高 H 是辅助半层：当 $k=2h-1$ 时其补集大小为 q，可直接读 D；当 $k=2h$ 时补集大小为 h，任意非空拆分两侧都不超过 q，直接 pair 与图闭包实现缺失的 D(h)。较低 H 层也需要必要的直接 pair，不能只给最高层播种。

### 8.3 边界完成与实现

每张 H 完成后枚举低层锚定集合 $L\subseteq S$，在共同根结算：

```math
U\leftarrow\min\{U,A(L,v)+D(S\setminus L,v)+H(S,v)\},\qquad |L|\le\ell.
```

这里 ordinary 块属于前向 A 跨边界的一侧，仍用规范 branch。若 $k=2h$，还需处理两块都由辅助 H 表示的半层完成：

```math
U\leftarrow\min\{U,d_a(v)+H(S,v)+H(N\setminus S,v)\},\qquad |S|=h.
```

这些完成式与 Base 的平衡分解一一对应。高层 A 不再物化，但其必要的外侧组合与图闭包被 H 保留。

转置每次只聚合 64 个连续顶点，将 mask-major 稀疏 D 行转为顶点局部的候选集合，处理后复用容器。64 与位图 word 对齐，与线程数无关。双块候选使用“值减对应势”的 reduced value 过滤，并按确定的枚举工作量选择 pair 扫描或互补 submask 扫描；两者候选集合相同。

## 9. 精确性与数值边界

精确性来自三个不变量。第一，任何用于降低 U 的值都来自真实路径、真实 rooted 子树及其连通组合，因此不小于全图最优值。第二，未剪枝 D/A 的合并与图闭包覆盖任意 rooted 树，规范 branch 的递归展开不丢失推导；H 的终端与 successor 逐个覆盖普通 split。第三，每次剪枝使用的剩余证书都不超过对应最优树分解中尚未支付的代价，所以如果仍有权值小于 U 的解，它的必要推导不会全部被删掉。

由平衡分解，Base 必能完成这个改善解；由补集转置的归纳与边界完成，Enhanced 也保留同一类改善解。因此全部必要层处理完后，当前 U 等于最优值。上下界提前闭合也是同一个结论。

实现保留原始 `double` 边权，不作整数化或单精度压缩。上下界闭合使用原始顺序比较，不用 epsilon 把正 gap 视为零；路径恢复允许容差，但最终按真实原边计费。浮点包围区间无法决定 dual 比较时执行逐组求和，较小标签仍可继续未完成的证书阶段。

这里的“精确”指组合搜索不引入近似比或容许误差，并不声称任意实数输入上的任意精度运算。实现以 `1e100` 为无穷哨兵，要求相关有限费用和中间和远小于这一值。极端量级、累积舍入与溢出仍受浮点表示限制；跨实现比较应同时说明输入精度与数值口径。

## 10. 复杂度与统计量

令 $F=\sum_i|K_i|$，witness、facility、支撑图分别涉及 $t,\rho,s$ 个顶点。无条件完整的子集 DP 组合项为 $O(3^g n)$；二叉堆图闭包通常写作 $O(2^g(m+n)\log(n+m))$，但“每状态永久关闭一次”不是当前分阶段缓存的实现不变量。

更准确地，令 M 为实际子集枚举、表查找、合并、转置和排序工作量（包括空扫描及二分比较），R 为实际扫描的邻接项数，P 为总入堆与出堆次数，Q 为最大堆长，C 为下界查询实际工作，则主状态搜索成本为：

```math
O\bigl(M+R+P\log(Q+1)+C\bigr).
```

这个式子包括重复入堆和重新展开，不把它们藏在状态数里。其他阶段的保守成本如下；可被购买多次的 DP 按实际购买次数累计。

| 阶段 | 时间 | 主要额外空间 |
|---|---|---|
| 加载与普通连通分量 | $O(n+m)$ 加输入解析 | $O(n+m)$ |
| 分量 cover | 正权时 $O(F\log(F+1)+3^g)$；含零权时保守另加 $O((n+m)\log(n+1))$ | $O(F+2^g)$，含零权另加 $O(n)$ |
| 组距离 | $O(g(m+n)\log(n+m))$ | 至多 $O(gn)$ |
| tour | $O(2^g g^3)$ | $O(2^g g^2)$ |
| 三元路径生长 | 保守 $O(g^4(n+m))$ | $O(n+m+F)$ |
| 购买后的四元路径生长 | 保守 $O(g^5(n+m))$ | $O(n+m+F)$ |
| 单次 witness DP | $O(t3^k+t2^k\log(n+1))$ | $O(t2^k)$ |
| directed-cut 构造/一次补全 | $O(gm+g(m+n)\log(n+m))$ | $O(gn+m)$ |
| facility DP | $O(\rho(m+n)\log(n+m)+2^g\rho^2+3^g\rho)$ | $O(n+\rho^2+2^g\rho)$ |
| 支撑图首次 DP | $O(s^3+2^k s^2+3^k s+2^k s\log(n+1))$ | $O(s^2+2^k s)$ |

主状态持久空间至多 $O(2^g n)$。实际令 $Z_D,Z_A,Z_H$ 为保存的行项数，Base 主要保存 $Z_D+Z_A$，Enhanced 主要保存 $Z_D+Z_A+Z_H$，再加距离、tour、A1 查询缓存和已购买支撑图。A1 排名只用 $O(kn+2^k)$ 的 byte/整数缓存，不复制 double 距离；堆工作区的峰值也应另计，不能从最终 payload 推断。

输出 `mask_vertex_states` 累计各 D/A/H 逻辑行首次发现的有限候选数：同一行的后续距离改进不重复计；不同状态族分别计；移交 A1 不重复计；末层只消费的 A 也计入。A1 重启时只发布并登记最终 pass。组距离、dual、tour、转置终端、虚拟拒绝阈值和完整解结算不计入。

这个统计量解释主状态规模，但不等于结束时保存数量，也不等于峰值空间。公平的运行比较仍需单独测时间和峰值内存；本发行程序的逐查询计时不包含加载，不内置内存采样线程或时间上限。
